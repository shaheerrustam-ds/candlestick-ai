# Candlestick AI – AI‑Powered Trading Assistant

## 🚀 Live Demo (AI Seekho 2026 Submission)
👉 [https://candlestick-ai-seekho.web.app](https://candlestick-ai-seekho.web.app)

## 📌 About This Repository
This project contains two versions:

1. **`index.html`** – Final single‑file submission for AI Seekho 2026 Phase 1.  
   Built with Google AI Studio, Gemini API, Lightweight Charts, Firebase Hosting.  
   Fully functional – no build step, just open in a browser.

2. **`/frontend` & `/backend`** – Original full‑stack source code (React + Node.js).  
   Planned for future enhancement with real market data and user accounts.

## ✨ Features (in the live demo)
- Interactive candlestick chart (Lightweight Charts)
- Pattern detection: Doji, Hammer, Bullish/Bearish Engulfing with confidence scores
- AI chat assistant (Tradexa) powered by Gemini API
- Paper portfolio: $10k virtual cash, buy/sell, reset, P&L tracking
- Upgrade mock payment modal (plan badge changes)
- News feed with sentiment badges (bullish/bearish/neutral)
- Multi‑language support (English, Urdu, Roman Urdu, etc.)
- Deployed on Firebase Hosting – always accessible

## 🛠️ Tech Stack (Live Demo)
- HTML5 / CSS3 / JavaScript
- Lightweight Charts (TradingView)
- Gemini API (Google AI Studio)
- Tailwind CSS
- Firebase Hosting
- GitHub Copilot (used during development)

## 📂 How to Run Locally
1. Clone this repository.
2. Open `index.html` in any browser (Chrome, Firefox, Edge).
3. (Optional) Get a free Gemini API key from [aistudio.google.com](https://aistudio.google.com) and paste it in the top bar to enable AI chat.
